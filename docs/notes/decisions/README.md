# Decision records

One note per decision that closed off a real alternative, newest last. Use
`_templates/decision.md`. Name them `NNNN-short-slug.md` (`0001-…`).

Worth a note: choosing a compute platform, changing the panel cohort definition,
dropping a source, changing a model family, accepting a data-quality compromise.

Not worth a note: anything reversible in an hour.

Report 4 must explain design changes against the proposal — these notes are that
explanation, written while the reasoning is still fresh.
